Soporte

Estamos para ayudarte.

Si tienes una consulta o encuentras un problema con una de nuestras aplicaciones, puedes escribirnos directamente.

Correo de soporte

multicalcstudios@gmail.com

Para reportar un problema

Incluye la versión de la app, el modelo del dispositivo y una descripción del problema.

  1. Indica el nombre de la aplicación y su versión.
  2. Añade el modelo del dispositivo y, si lo conoces, la versión de Android.
  3. Describe qué intentabas hacer, qué ocurrió y los pasos para reproducirlo.

Evita incluir información personal o datos de conteos que no sean necesarios para explicar el problema.
